精神的な現象を物理の概念になぞらえたとき、何を表現でき、どこで対応が成り立たなくなるかを探る研究の初稿です。

## ローカルで開く

リポジトリをダウンロードまたはクローンし、`simulator/index.html` をブラウザーで開き、「動きを見る」を押してください。初めて開くと「ひと続きで見る」が表示されます。以前の選択が保存されている場合は、場面から選べます。ビルドやパッケージのインストールは不要で、外部ファイルの読み込みもありません。

## 見られること

- **ひと続きで見る**：左から右へ流れる情報粒子が思考の引力で曲がり、近くを通るものが集まる様子と、情報のコピー、引力の成長を一つの図で再生します。薄い輪は、思考がなければ通っていた位置です。同じ情報の到着区間を、外の時計と手元の時計で比較します。外で10秒に対応する手元の経過時間は約6.32秒です。条件を固定した説明用のシナリオです。
- **集める・分ける・育つ**：同じ流れから、自分だけの場合と、隣に強い集積がある場合を比較します。「隣の集積」「情報共有」「蓄積による成長」を切り替え、情報を自分で捕捉する効果と、コピーを受け取る効果を見分けられます。
- **重力と時間の尺度**：同じ外部時間の間に、重力源の近くで静止した時計が刻む時間を、無限遠の基準時計と比較します。質量の条件を変えて、局所の経過時間が短くなる様子を観察できます。
- **作用反作用**：等大・逆向きの力を受ける二つの物体を観察します。質量が2倍なら加速度と移動距離は半分になります。

再生は有限時間で終了し、繰り返して比較できます。動きを減らす設定では途中のアニメーションを省き、終了状態を表示します。

一連の表示で短くなるのは、外の時計と比べた手元の経過時間です。同じ情報を手元の1秒あたりで見ると、多く受け取る対応になります。時計の遅れだけで、外部基準の収集時間が短くなるとはしていません。

## 比喩と実証の境界

この試作は、仮定したモデルの動きを見るためのものです。思考が実際の重力を生むこと、精神的な現象が物理法則と同じであること、因果応報が実証された法則であることを示しません。画面上の物理パラメーターを人の能力や道徳の評価には使いません。

中心での捕捉、情報のコピー、蓄積による引力の成長は、この試作に追加した仮定です。隣に強い引力があるだけで、自分の収集が必ず増えるとは限りません。

相対論の場面では、球対称・非回転の重力源の外で静止した時計について、シュワルツシルト時空での進行比を計算します。一連の表示も、この静的な条件を同じ到着区間の時間比較に使います。粒子の集積は引力・捕捉・共有の別のモデルで、成長する引力から時空を解く連成計算はしていません。情報共有の表示は、理解や学習の成立を保証しません。

## 今後の検討

- **教育と情報共有**：コピーを受け取ることと、情報の意味を理解し、使えるようになることの違いを検討します。
- **時間の尺度**：外部基準の経過時間、手元の経過時間、それぞれの時間あたりの情報受信量を区別します。
- **因果応報と作用反作用**：物理での相互作用は二つの物体に同時に等大・逆向きの力として働きます。後で返ってくる社会的・心理的な結果とは、時間関係や作用する対象が異なります。
- **モデルの検証**：粒子や力の数値的な振る舞いと、精神的な現象についての観察・検証を分け、それぞれの仮定と限界を記録します。
