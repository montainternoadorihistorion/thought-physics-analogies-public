# モデルの仮定と限界

この試作の目的は、「集める → 分ける → 蓄積が次の収集につながる」と「同じ情報を受け取る区間が、外の時計と手元の時計で異なる長さになる」という対応を、操作しながら検討することです。人間の能力や精神力を測る尺度ではありません。

## ひと続きで見る

最初の場面では、左から右へ流れる粒子が思考の引力で曲がって集まり、情報のコピーが隣から届き、取得した情報によって引力が成長して引き込める幅が広がる様子を、一つの図で再生します。同じ情報の到着区間を外の時計と手元の時計で比較します。

条件は、学ぶ人の初期引力1、隣の収集者・共有・成長あり、時計の条件 `u = 0.6` に固定しています。詳しい比較で選んだ条件はそのまま保持し、一連のシナリオへは混ぜません。

物語の再生時刻は0〜6.5です。通常は約6.5秒のアニメーションになります。最初の6まで粒子を動かし、残りの0.5は送信済みコピーの配送を進めます。段階の表示は注目する働きを示しており、情報の捕捉・共有・成長は一部並行して起きます。

外の基準時計の経過時間を `t`、手元の時計を `τ` とし、静的な条件で `τ = t × √(1 − 0.6)` とします。図の再生区間0〜6.5を外の時計0〜10秒に対応づける表示用の換算をしています。終了時には、同じ到着イベントの区間が外では10秒、手元では約6.324555秒になります。

ここでの短さは手元の経過時間の短さです。同じ情報数 `N` を区間平均で比べると、`N / τ = (N / t) / √(1 − u)` なので、手元の1秒あたりの受信量は大きくなります。開始時点の0秒について率は計算しません。一定の外部到着頻度の信号なら、これも同じ向きの対応になります。

時計の遅れだけで、外部基準の情報収集が速くなるわけではありません。図の粒子の引き寄せ・捕捉・情報共有と、静的な時計の関係は別の計算です。成長する比喩の引力から時空を解いたり、光子の軌道や伝播遅延を解いたりする連成計算はしていません。

## 情報の集積・共有・成長

左右の比較は同じ初期配置と同じ流れから始めます。元の粒子を情報に見立て、左から右へほぼ一定の速さで流しながら、中心からの引力で曲げます。中心は固定し、近距離では引力が発散しないように補正しています。中心の捕捉域を横切った粒子は取り込み、横切らなかった粒子は曲がったまま通り過ぎます。捕捉と中心の固定は追加したルールで、孤立した重力系の保存則を再現するものではありません。粒子同士の引力や、中心の運動は扱いません。

薄い輪は、引力がなければその粒子が同じ時刻にいたはずの位置（初期位置から初速のまま直進した位置）で、細い線は実際の位置との差を示します。差が4以上で表示し、60を超えると薄くなり、120以上では表示しません。表示上の補助であり、計算には影響しません。

点質量近似では、速さ `v` で近づく粒子が捕捉半径 `r_c` の内側を通る条件は、衝突径数 `b` について `b² ≤ r_c² + 2GM·r_c / v²` です。引力 `M` が大きいほど、引き込める幅が広がります。この試作の補正付きの引力では、この幅より少し狭くなり、二つの中心がある場合はさらにずれます。引力の成長は、この幅が広がる動きとして画面に現れます。

隣の強い集積にも引力があります。それだけで自分の捕捉が増えるとは限らず、同じ粒子を取り合うこともあります。「情報共有」を有効にすると、隣が捕捉した情報のコピーを受け取ります。これは引力とは別に加えた伝達ルールであり、元の情報は隣に残ります。

情報にはそれぞれ識別子を付け、自分で集めたものと受け取ったコピーを重複して数えません。共有コピーを元の粒子の個数に混ぜないため、情報を分けることと、物質の粒子が移動することの違いを確認できます。理解、記憶の正確さ、忘却、学習への利用はモデルに含めていません。

「蓄積による成長」を有効にすると、取得した異なる情報の数に応じて、モデル上の引力が有限の範囲で増えます。既知の情報が次の探索の手掛かりになる様子に対応させた仮定です。「情報が多いほど必ず正しい」「蓄積が実際の重力を生む」という主張ではありません。

### 再現用の設定

- 画面内の初期粒子は72個、乱数の初期値は38123です。流れが途切れないように、左側の上流360（流速60×6秒）の範囲に同じ密度で65個を追加し、合計137個です。400×240の固定した計算領域を使うため、表示幅を変えても取得結果は変わりません。
- 各粒子の初速は、右向きに60の±10%（一様乱数）、上下方向に±5の範囲です。右端から30、上下に60を超えて出た粒子は計算から外し、表示しません。
- 学ぶ人の中心は `(145, 135)`、隣の収集者は `(300, 100)` です。学ぶ人の基礎引力は0.5〜3、収集者は3.8。距離、質量、時間は試作用の尺度です。
- 中心から粒子へのベクトルを `r`、実効引力を `M` とし、加速度を `110000 × M × r / (|r|² + 20²)^(3/2)` とします。二つの中心がある場合は加速度を足し合わせます。時間刻みは1/120、捕捉半径は15です。
- 成長倍率は `1 + 1.8 × min(K / 48, 1)` で、上限は2.8倍です。学ぶ人の `K` は直接取得と受信済みコピーの異なるID数、収集者の `K` は自身の捕捉数です。成長を切ると倍率は1のままです。
- 計算上の時間6まで粒子を動かし、最後の0.5は送信済みコピーの配送だけを進めます。コピーは0.48後に届き、届いてから取得数と引力に反映します。送り先は固定した隣の学ぶ人だけで、双方向の再配布はありません。

途中の描画頻度や画面幅で計算条件を変えず、設定を変えたときに同じ初期配置へ戻ります。一時停止からは続き、終了後の再生は初めからです。広い表示幅では横方向の引き伸ばしを1.5倍までに抑え、図を中央に寄せます。これは表示だけの処理です。

## 重力と時間の尺度

この場面では「同じ外部時間の間に、近くの時計が刻む時間はどれだけか」を表示します。基準は無限遠の時計、比較対象は球対称・非回転・無電荷の重力源の外で、一定の半径に静止している時計です。自由落下や周回する時計は扱いません。

無限遠の基準時間を `Δt`、局所の経過時間を `Δτ`、質量を `M`、面積が `4πr²` となる半径を `r` とすると、シュワルツシルト時空での関係は次のとおりです。

`u = 2GM / (rc²)`

`Δτ = Δt × √(1 − u)`

出典：[Andrew Hamilton, More about the Schwarzschild Geometry（JILA）, Gravitational slowing of time](https://jila.colorado.edu/~ajsh/courses/bh/schwp.html)。

質量のスライダーは、半径を固定し、異なる静的な質量条件を選び直す操作です。選択時には時間を初期化します。時間変化する質量に対して重力場を解く計算はしていません。

`u` は0〜0.8、刻みは0.05です。静止した時計を扱える領域に保ち、無限遠で10秒が経過する間の時計の進み方を比較します。

| 条件 | 近くの時計の進行比 | 無限遠で10秒の間の局所経過時間 |
| --- | ---: | ---: |
| `u = 0` | 1 | 10秒 |
| `u = 0.6` | 約0.632456 | 約6.324555秒 |
| `u = 0.8` | 約0.447214 | 約4.472136秒 |

時計が置かれた場所では、その時計は通常どおり進みます。ここでの短さは、離れた基準時計と比較した局所経過時間の短さです。スライダーの条件では時計は止まりません。

同じ到着イベント列を二つの時計で測れば、近くの手元の時計では受信区間が短くなり、手元の1秒あたりの受信頻度は高くなります。これは外部基準の到着時刻そのものを早めることとは異なります。静的な重力場で遠方から近くへ届く光の青方偏移とも同じ向きです。前掲のJILAの資料は、時計の遅れと光の青方偏移を説明しています。この図は、その光の伝播を数値計算したものではありません。

重力ポテンシャルによる時計の進み方の差は、光原子時計による実験でも調べられています。参考：[Chou ほか, Relativity and Optical Clocks（NIST、2010）](https://www.nist.gov/publications/relativity-and-optical-clocks)。

## 作用反作用

二つの物体の相互作用として、短時間、等大・逆向きの力を仮定し、その後は等速で動きます。同じ力でも質量が2倍なら加速度は半分になるため、二つとも静止状態から、同じ時間だけ力を受けるこの場面では、移動距離も半分になります。

この力の対は同時に別々の物体へ働きます。後で返ってくる社会的・心理的な結果や、道徳的な報いを保証する法則とは異なります。

## 行いと作用反作用（別ページ）

`simulator/reaction.html` は、自分（質量60）と相手だけの閉じた系で、摩擦や抵抗はありません。働きかけは短い力積として扱い、相手に `J` を与えると同時に自分は `−J` を受けます。相手に与えた運動量のベクトル和と、自分の運動量（質量×速度）は、常に大きさが等しく向きが逆です。

- 軽いもの：質量1。0.6秒ごとに10回、1回あたり力積120（相手の速さは120）。自分の速さは1回あたり2増え、終わりに20になります。
- 重いもの：質量40。1.2秒に1回、力積1200（相手の速さは30）。自分の速さは一度に20になります。
- 同じ向きの場合、働きかけの向きは右向きに固定し、相手は自分から見て右向き±60度以内で最も近い、まだ押していないものを選びます。いろいろな向きの場合は、固定した10方向（0, 40, 320, 150, 200, 80, 280, 20, 340, 120度）の順に働きかけ、その向きの±60度以内で最も近いものを選びます（なければ最も近いもの）。合計のベクトルの大きさは約318.98で、自分の終わりの速さは約5.32です。
- 周りの軽いものは乱数（初期値90211）で、表示幅×220の面積3000あたり1個（最少40個）を配置し、±4の遅い漂いを与えています。さらに、働きかけの向きごとに手の届く範囲（自分から30〜84、向きは±18度）へ候補を1個ずつ置き、どの幅でも近くのものに働きかけるようにしています。背景の配置は表示幅に依存しますが、与える力積と向きは固定なので、合計と自分の速さは幅によらず同じです。
- 再生は7秒です。矢印は力積と運動量を同じ尺度（0.1）で描き、対になる矢印は常に同じ長さです。

ここで返るのは運動量であり、後から返ってくる社会的・心理的な結果や、道徳的な報いを保証する法則ではありません。同じ合計でも、一度に返るか小さく分かれて返るかで気づきやすさが変わることと、向きがばらばらだと打ち消し合うことだけを示します。

## 比較の方法

- 隣を無効にし、同じ設定で二つの配置の結果が一致するかを確かめます。
- 隣を有効にしたまま共有を切り、元の粒子の捕捉と、コピーを受け取る効果を分けて見ます。
- 成長の有無を変え、同じ情報の初期配置から取得数と引力の変化を比べます。
- 時計の比較では質量の静的な条件を変え、同じ外部時間に対する手元の経過時間の変化を確かめます。

表示の動きが仮定どおりであることと、その仮定が人間の現象をよく説明することは、別々に検証する必要があります。

## 動作確認

Chromium でローカルの HTML を直接開き、初期引力1、固定した初期配置と流れで次の終了結果を確認しました（2026年10月18日、流れの導入後）。数値は、この仮定と配置に対する結果です。

| 学ぶ人の条件 | 自分で捕捉 | 共有で受信 | 異なる情報の合計 |
| --- | ---: | ---: | ---: |
| 単独、成長なし | 21 | 0 | 21 |
| 単独、成長あり | 25 | 0 | 25 |
| 隣あり、成長あり、共有なし | 21 | 0 | 21 |
| 隣あり、成長あり、共有あり | 29 | 51 | 80 |

隣の有無・共有・成長の8通りで、元の粒子137個の識別子と重複のない取得数を確認し、画面の外で同じ計算を複製した結果と一致しました。表の共有ありの例では、収集者が保持する51個はコピー後も残ります。成長なしで隣あり・共有ありの場合は自分で22、共有58の合計80になります。学ぶ人が育つと、上流で先に捕捉する分だけ収集者の捕捉が減ります。単独・成長ありで初期引力を0.5と3にすると、自分で捕捉する数は17と66です。

開始・一時停止・再開・終了、保存した場面と設定の再読み込み後の復元、320px（明）・736px（明）・1024px（暗）での表示、オフライン、動きを減らす設定で動作し、ブラウザーのエラーと外部 HTTP 通信は観測しませんでした。再生の途中（外の時計4秒付近）には輪と線が表示され、一時停止で経過時間が止まることを確認しています。時計と作用反作用の場面は、この変更で描画を変えておらず、終了まで動いて従来の結果が表示されることだけを確認しました。不正な保存設定からの復帰と、同じ設定の再通知の確認は、流れ導入前の記録（保存処理の修正時）のままです。

相対論の場面では、`u = 0 / 0.6 / 0.8` で局所経過時間が `10 / 約6.324555 / 約4.472136秒` になること、途中の条件でも単調に変化することを、数値、針の角度、表示された棒の長さで確認しました。

一連の表示では、粒子と共有コピーが動き、引力が育つことを、実際の再生で確認しました。同じ収集区間が外の時計10秒、手元の時計約6.324555秒になることを、途中の時刻と終了時の表示で確認しています。固定シナリオと詳しい比較の保存設定が混ざらないことも確認しました。
